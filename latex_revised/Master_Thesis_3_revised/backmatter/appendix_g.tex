\section*{G.2 Voice-Bridge Grammar}

The Vosk-based speech-recognition front-end uses a closed grammar to map utterances to runtime tokens. The 16 phrases recognised by the system are shown in Table~\ref{tab:app_g_grammar}. Each phrase produces a single token over UDP port~5006 to the live runtime; the runtime then dispatches the token through the same target-selection or command path used for keyboard input. The voice front-end does not bypass any safety gate.

The grammar is intentionally small: a closed vocabulary improves recognition accuracy with the offline Vosk acoustic model and avoids out-of-vocabulary tokens being mapped to unintended actions. Phrases are recognised when they appear at the start of an utterance; trailing speech is ignored.

# ASME Numeric Reference Style for Word

## In-text citation
- Use numeric references in square brackets in order of appearance.
- Examples: `[1]`, `[2,3]`, `[5-7]`

## Reference list rules
- Order references by first appearance in text.
- No footnotes for bibliography references.

## Journal article format
`[n] AuthorLastName, Initials., Year, "Article Title," Journal Name, Volume(Issue), pp. xx-yy.`

## Book format
`[n] AuthorLastName, Initials., Year, Book Title, Publisher, City, pp. xx-yy, Chap. N.`

## Conference format
`[n] AuthorLastName, Initials., Year, "Paper Title," Conference Name, City, pp. xx-yy.`

## Thesis/report format
`[n] AuthorLastName, Initials., Year, "Title," Ph.D./M.Sc. thesis (or Technical Report), Institution, City.`

## Notes for this thesis
- Keep repository artifacts in the same numeric list as standard references.
- Use consistent wording for internal artifacts, e.g.:
  - `internal artifact, Project_Cam repository`
